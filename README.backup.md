# Generation — Buổi 3

Website giới thiệu nền tảng lưu giữ gia phả trực tuyến, xây bằng HTML và Tailwind CSS v4.

## Trang

- `index.html` — Trang chủ và tính năng
- `pricing.html` — Bảng giá, so sánh tính năng và câu hỏi thanh toán
- `contact.html` — Form liên hệ có nhãn, trạng thái focus và thuộc tính hỗ trợ tiếp cận

## Chạy dự án

```bash
npm install
npm run build
```

Mở `index.html` bằng Live Server hoặc một static server. Nút sáng/tối trên header bật/tắt dark mode để kiểm tra giao diện.
